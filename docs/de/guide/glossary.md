# Glossar

| Begriff               | Englisch         | Bedeutung                                                                                                              |
| --------------------- | ---------------- | ---------------------------------------------------------------------------------------------------------------------- |
| **`.finsight`-Datei** | `.finsight` file | Die Datei, in der Family Insight einen ganzen Stammbaum speichert, einschließlich der Fotos.                           |
| **CSV**               | CSV              | Ein reines Textformat für Tabellen, mit dem Personen [importiert](./csv-import) und [exportiert](./csv-export) werden. |
| **Detailbereich**     | Details panel    | Der Bereich rechts mit den Daten, der Familie und der Zeitleiste der ausgewählten Person.                              |
| **Generation**        | Generation       | Eine Ebene des Stammbaums: Eltern stehen eine Generation über ihren Kindern.                                           |
| **Genauigkeit**       | Qualifier        | Ob ein Datum genau, _etwa_, _vor_ oder _nach_ ist (`~`, `<`, `>`).                                                     |
| **Geburtsname**       | Birth surname    | Der Nachname, mit dem eine Person geboren wurde (Mädchenname), angezeigt als „geb. …“.                                 |
| **Halbgeschwister**   | Half-sibling     | Bruder oder Schwester mit nur einem gemeinsamen Elternteil.                                                            |
| **Hauptperson**       | Root person      | Die Person, von der die Vorfahren- und Nachkommen-Ansichten ausgehen, markiert mit 🏠.                                 |
| **Karte**             | Card             | Das Kästchen, das eine Person im Stammbaum darstellt (nicht zu verwechseln mit der Karte der Orte).                    |
| **Nachkommen**        | Descendants      | Kinder, Enkel, Urenkel einer Person und so weiter; auch die Ansicht, die sie zeigt.                                    |
| **Partnerschaft**     | Partnership      | Eine Beziehung zwischen zwei Partnern: Ehe, Partnerschaft, Verlobung oder Zusammenleben.                               |
| **Sanduhr**           | Hourglass        | Eine Ansicht mit den Vorfahren einer Person darüber und den Nachkommen darunter – geformt wie eine Sanduhr.            |
| **Stiefelternteil**   | Step-parent      | Ein Elternteil durch Heirat statt durch Geburt; Adoptiv- und Pflegeeltern werden ähnlich erfasst.                      |
| **Übersichtskarte**   | Overview map     | Die kleine Karte des ganzen Stammbaums in der linken unteren Ecke (Minimap).                                           |
| **Vorfahren**         | Ancestors        | Eltern, Großeltern, Urgroßeltern einer Person und so weiter; auch die [Ansicht](./view-modes), die sie zeigt.          |
| **Zeitleiste**        | Timeline         | Die Liste der Lebensereignisse (Geburt, Ehen, Kinder, Tod) im Detailbereich.                                           |
