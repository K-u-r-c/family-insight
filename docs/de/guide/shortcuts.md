# Tastenkürzel

Drücken Sie im Programm <kbd>?</kbd> oder <kbd>F1</kbd> (oder wählen Sie **Hilfe → Tastenkürzel**),
um diese Liste zu sehen:

<Screenshot name="shortcuts" alt="Das Fenster Tastenkürzel mit den Gruppen Dateien, Bearbeiten, Stammbaum und Allgemein" />

<ShortcutTable />

Die Tasten der Gruppe **Stammbaum** funktionieren, wenn der Stammbaum den Tastaturfokus hat –
klicken Sie zuerst in den Stammbaum, oder siehe [Mit der Tastatur bewegen](./navigation#keyboard).

## Mehr in der Menüleiste

| Aktion                   | Windows / Linux                                             | macOS                                               |
| ------------------------ | ----------------------------------------------------------- | --------------------------------------------------- |
| Vergrößern / verkleinern | <kbd>Ctrl</kbd>+<kbd>=</kbd> / <kbd>Ctrl</kbd>+<kbd>-</kbd> | <kbd>⌘</kbd><kbd>=</kbd> / <kbd>⌘</kbd><kbd>-</kbd> |
| Zoom auf 100 %           | <kbd>Ctrl</kbd>+<kbd>0</kbd>                                | <kbd>⌘</kbd><kbd>0</kbd>                            |
| Vollbild                 | <kbd>F11</kbd>                                              | <kbd>⌃</kbd><kbd>⌘</kbd><kbd>F</kbd>                |

Die Menüleiste zeigt das Kürzel außerdem neben jedem Befehl an.
