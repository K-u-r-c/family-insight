# Updates

Family Insight prüft einmal am Tag, ob eine neue Version verfügbar ist. Dabei wird nur die Version
der App an GitHub gesendet, wo die Versionen veröffentlicht werden – keine Ihrer Daten.

## Wenn eine neue Version verfügbar ist

In der rechten unteren Ecke erscheint ein Hinweis:

<Screenshot name="update-available" alt="Der Hinweis Family Insight 1.2.0 ist verfügbar mit den Schaltflächen Herunterladen, Versionshinweise, Später und Diese Version überspringen" />

- **Herunterladen** – lädt das Update im Hintergrund herunter; ein Fortschrittsbalken zeigt, wie
  weit es ist.
- **Versionshinweise** – was in dieser Version neu ist.
- **Später** – blendet den Hinweis bis zum nächsten Start aus.
- **Diese Version überspringen** – keine Erinnerungen mehr an diese Version (die nächste wird
  wieder angeboten).

<Screenshot name="update-notes" alt="Das Fenster Neu in 1.2.0 mit Überschriften und einer Liste der Änderungen" />

Ist der Download fertig, wählen Sie **Jetzt neu starten** – Family Insight bittet Sie, ungespeicherte
Änderungen zuerst zu speichern, und startet dann in der neuen Version. **Beim Beenden** installiert
das Update, wenn Sie das Programm das nächste Mal schließen.

::: info Portable, deb- und macOS-Versionen
Das portable Windows-Programm, das deb-Paket für Linux und die macOS-App können sich nicht selbst
ersetzen. Bei ihnen öffnet **Downloadseite** die Release-Seite, von der Sie die neue Version wie
gewohnt herunterladen (siehe [Installation](./install#updating)).
:::

## Jetzt suchen oder die Suche ausschalten

Im Einstellungsmenü (**⚙**, oben rechts):

- **Automatisch nach Updates suchen** – standardmäßig eingeschaltet; schalten Sie es aus, wenn Sie
  lieber von Hand aktualisieren.
- **Jetzt suchen…** – sucht sofort und sagt Ihnen, ob Sie bereits die neueste Version haben.
  Daneben steht der Zeitpunkt der letzten Suche.

**Nach Updates suchen…** finden Sie auch im Menü **Hilfe** (unter macOS im Menü
**Family Insight**).
