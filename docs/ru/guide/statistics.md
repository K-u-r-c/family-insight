# Статистика

Нажмите кнопку **Статистика** (📊) справа на панели инструментов или выберите **Вид → Статистика**
в строке меню:

## Цифры

- **человек** — все, кто есть в древе;
- **живущих** и **умерших** — по [сведениям о том, жив ли человек](./editing#life-status) (люди
  с неизвестным статусом не входят ни в одну группу);
- **поколений** — самая длинная линия от старшего предка до младшего потомка;
- **фактов с источником** — доля записанных фактов (дат, мест, событий жизни, связей), у которых
  есть ссылка хотя бы на один [источник](./sources);
- **средняя продолжительность жизни (лет)** — у умерших людей, для которых известны и дата
  рождения, и дата смерти. Под ней указано, кто прожил дольше всех; нажмите **Показать**, чтобы
  выбрать этого человека.

## Самые частые имена и места

Три списка показывают пять самых частых **имён** (учитывается первое имя), **фамилий** (фамилия
при рождении, если она указана) и **мест рождения**. Щёлкните по столбцу, чтобы
[найти](./search) это значение, — например, щёлкните по **Łódź**, чтобы увидеть всех, кто там
родился.

## События жизни

Ещё два списка показывают самые частые **события жизни** и **места событий**; щёлкните по месту,
чтобы найти его. Под ними видно, у скольких людей пока нет событий жизни
([События жизни](./events)).

## Дополнить

В последнем разделе перечислены люди, у которых **нет дат** (ни даты рождения, ни даты смерти)
или **нет родителей**. Это удобный список задач для ваших исследований — щёлкните по имени, чтобы
сразу перейти к этому человеку. Когда даты и родители есть у всех, там написано «У всех есть
даты и родители. Отличная работа!».
