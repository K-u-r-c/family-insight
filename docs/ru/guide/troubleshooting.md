# Решение проблем

## Программа не запускается

### Windows

| Признак                                                 | Причина и решение                                                                                                                               |
| ------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------- |
| Синее окно **«Система Windows защитила ваш компьютер»** | SmartScreen пока не знает издателя. Нажмите **Подробнее → Выполнить в любом случае** (см. [Установка](./install#windows)).                      |
| Антивирус блокирует или удаляет файл                    | Скачайте файл заново с официальной [страницы выпусков](https://github.com/K-u-r-c/family-insight/releases/latest) и разрешите его в антивирусе. |

### macOS

| Признак                                                                                 | Причина и решение                                                                                                                                                                             |
| --------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Не удаётся открыть программу «Family Insight», так как Apple не может проверить её…** | Программа пока не нотариально заверена. Щёлкните по ней правой кнопкой в папке «Программы» → **Открыть** или **Системные настройки → Конфиденциальность и безопасность → Всё равно открыть**. |
| **Программа «Family Insight» повреждена, и её не удаётся открыть**                      | Карантин macOS. Один раз выполните в Терминале `xattr -cr "/Applications/Family Insight.app"`.                                                                                                |
| Программа не запускается на Mac с Apple Silicon                                         | Возможно, у вас версия для Intel — скачайте `mac-arm64.dmg` (см. [Какой файл скачать?](./install#which-file)).                                                                                |

### Linux {#linux}

| Признак                                                                      | Причина и решение                                                                                                                                                                  |
| ---------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| При двойном щелчке по AppImage ничего не происходит                          | Файл не исполняемый: `chmod +x family-insight-*.AppImage`.                                                                                                                         |
| `dlopen(): error loading libfuse.so.2` / _AppImages require FUSE to run_     | Нет FUSE 2: `sudo apt install libfuse2` (в Ubuntu 24.04 и новее: `libfuse2t64`) или пакет `fuse2` / `fuse-libs` в других дистрибутивах.                                            |
| _The SUID sandbox helper binary was found, but is not configured correctly…_ | Некоторые дистрибутивы (например, Ubuntu 24.04) ограничивают песочницу, которой пользуется Electron. Установите вместо этого пакет `.deb` или запустите AppImage с `--no-sandbox`. |
| Окно размыто или мерцает в Wayland                                           | Запустите программу с `--ozone-platform=x11`, чтобы использовать XWayland.                                                                                                         |

Чтобы понять, что происходит, запустите программу из терминала — все сообщения об ошибках
выводятся туда.

## Кириллица в Excel отображается неправильно или всё оказалось в одном столбце

Экспортируйте CSV ещё раз и выберите разделитель **точка с запятой** — Excel с русскими
региональными настройками ожидает именно его. Файл всегда содержит метку UTF-8, поэтому русские
буквы (и такие, как ё, ą или ö) отображаются правильно. См. [Экспорт в CSV](./csv-export).

## При импорте CSV показаны проблемы

В каждом сообщении о проблеме указана строка и что нужно изменить. Полный список с решениями
приведён в разделе [Импорт из CSV → Проблемы и предупреждения](./csv-import#problems).

## Файл не открывается

| Сообщение                                                                  | Что делать                                                                                   |
| -------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------- |
| _Файл больше не существует. Возможно, его переместили или удалили._        | Найдите файл и откройте его командой **Открыть…**; уберите старую запись из списка недавних. |
| _У вас нет прав доступа к этому файлу._                                    | Скопируйте файл в свою папку (например, «Документы») и откройте копию.                       |
| _Это древо сохранено более новой версией Family Insight…_                  | [Обновите Family Insight](./install#updating).                                               |
| _Файл повреждён или не является древом Family Insight._                    | Откройте одну из [резервных копий](./files#backups) (`.bak1` … `.bak5`) рядом с файлом.      |
| _Это не файл древа Family Insight._ / _Этот тип файлов не поддерживается._ | Выберите файл `.finsight`; таблицы открываются через [Импорт из CSV](./csv-import).          |
| _Файл содержит недопустимые данные, и его нельзя безопасно открыть._       | Попробуйте резервную копию; если это не поможет, [сообщите о проблеме](#report-a-problem).   |

Если программа неожиданно закрылась, запустите её снова — она предложит
[восстановить несохранённую работу](./files#crash-recovery).

## Сообщить о проблеме {#report-a-problem}

Выберите **Справка → Сообщить о проблеме…** — откроется страница обращений на GitHub (нужна
бесплатная учётная запись GitHub). Пожалуйста, укажите:

- что вы делали, чего ожидали и что произошло вместо этого;
- версию (**Справка → О программе Family Insight**) и вашу систему (например, Windows 11,
  macOS 15, Ubuntu 24.04);
- снимок экрана с сообщением и вывод терминала, если вы запускали программу из него.

Не прикрепляйте своё родословное древо публично — в нём личные данные. Если файл нужен, напишите
об этом в обращении, и мы договоримся о закрытом способе передачи. Писать можно и по-русски.
