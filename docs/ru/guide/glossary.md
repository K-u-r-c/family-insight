# Словарь терминов

| Термин                                 | По-английски     | Значение                                                                                                                        |
| -------------------------------------- | ---------------- | ------------------------------------------------------------------------------------------------------------------------------- |
| **Брат или сестра по одному родителю** | Half-sibling     | Брат или сестра, с которыми общий только один родитель.                                                                         |
| **CSV**                                | CSV              | Простой текстовый формат таблиц, через который людей можно [импортировать](./csv-import) и [экспортировать](./csv-export).      |
| **Карточка**                           | Card             | Прямоугольник, который обозначает одного человека в древе.                                                                      |
| **Неродной родитель**                  | Step-parent      | Родитель по браку, а не по рождению (отчим, мачеха); приёмные родители и опекуны записываются так же.                           |
| **Обзорная карта**                     | Overview map     | Маленькая карта всего древа в левом нижнем углу (мини-карта).                                                                   |
| **Основное лицо**                      | Root person      | Человек, от которого начинаются режимы «Предки» и «Потомки»; отмечен значком 🏠.                                                |
| **Панель подробностей**                | Details panel    | Панель справа с данными, семьёй и хронологией выбранного человека.                                                              |
| **Песочные часы**                      | Hourglass        | Режим просмотра, в котором предки человека находятся сверху, а потомки снизу, — по форме он похож на песочные часы.             |
| **Поколение**                          | Generation       | Один уровень древа: родители находятся на поколение выше своих детей.                                                           |
| **Потомки**                            | Descendants      | Дети, внуки и так далее; также режим просмотра, который их показывает.                                                          |
| **Предки**                             | Ancestors        | Родители, бабушки и дедушки, прабабушки и прадедушки и так далее; также [режим просмотра](./view-modes), который их показывает. |
| **Союз**                               | Partnership      | Отношения двух партнёров: брак, партнёрство, помолвка или совместная жизнь.                                                     |
| **Точность даты**                      | Qualifier        | Указывает, точная ли дата или _около_, _до_, _после_ (`~`, `<`, `>`).                                                           |
| **Файл `.finsight`**                   | `.finsight` file | Файл, в котором Family Insight сохраняет всё древо, включая фото.                                                               |
| **Фамилия при рождении**               | Birth surname    | Фамилия, с которой человек родился (девичья фамилия); показывается как «урожд. …».                                              |
| **Хронология**                         | Timeline         | Список событий жизни (рождение, браки, дети, смерть) на панели подробностей.                                                    |
