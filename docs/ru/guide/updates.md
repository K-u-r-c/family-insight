# Обновления

Раз в день Family Insight проверяет, не вышла ли новая версия. На GitHub, где публикуются
выпуски, отправляется только номер версии программы — никаких ваших данных.

## Когда доступна новая версия

В правом нижнем углу появляется уведомление:

<Screenshot name="update-available" alt="Уведомление «Доступна версия Family Insight 1.2.0» с кнопками «Загрузить», «Что нового», «Позже» и «Пропустить эту версию»" />

- **Загрузить** — загружает обновление в фоновом режиме; индикатор показывает ход загрузки.
- **Что нового** — что изменилось в этой версии.
- **Позже** — скрывает уведомление до следующего запуска.
- **Пропустить эту версию** — больше не напоминать об этой версии (следующая будет
  предложена).

<Screenshot name="update-notes" alt="Окно «Что нового в версии 1.2.0» с заголовками и списком изменений" />

Когда загрузка завершится, выберите **Перезапустить сейчас** — Family Insight сначала предложит
сохранить несохранённые изменения, а затем перезапустится в новой версии. **При выходе**
устанавливает обновление, когда вы в следующий раз закроете программу.

::: info Переносная версия, пакет deb и macOS
Переносная программа для Windows, пакет deb для Linux и программа для macOS не могут заменить
себя сами. Для них кнопка **Страница загрузки** открывает страницу выпуска, где новую версию
можно скачать как обычно (см. [Установка](./install#updating)).
:::

## Проверить сейчас или отключить проверку

В меню настроек (**⚙**, справа вверху):

- **Проверять обновления автоматически** — включено по умолчанию; выключите, если предпочитаете
  обновлять программу вручную.
- **Проверить сейчас…** — проверяет немедленно и сообщает, если у вас уже последняя версия.
  Рядом показано время последней проверки.

Команда **Проверить обновления…** есть также в меню **Справка** (в macOS — в меню
**Family Insight**).
