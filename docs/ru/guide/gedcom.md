# GEDCOM

**GEDCOM** — это формат файлов, с помощью которого генеалогические программы обмениваются
родословными древами. Family Insight читает файлы GEDCOM 5.5, 5.5.1 и 7.0 (`.ged`, а также `.gdz`
с фото внутри) и записывает версии 5.5.1 или 7.0.

## Импорт файла GEDCOM

Выберите **☰ → Импорт GEDCOM…** (или **Файл → Импорт → GEDCOM…**, или **Импорт из GEDCOM…**
на экране приветствия) либо просто перетащите файл `.ged` в окно. Откроется предпросмотр:

<Screenshot name="gedcom-import" alt="Окно «Импорт GEDCOM»: GEDCOM 5.5.1, программа MyHeritage, кодировка UTF-8 (определена автоматически), предупреждение о приблизительной дате, теги, которые не импортированы, и сводка с людьми, семьями, событиями, источниками и медиафайлами" />

- В окне показаны **версия** и **программа**, которая записала файл, а также сколько в нём людей,
  семей, событий, источников и фото.
- **Кодировка** — определяется автоматически (UTF-8, UTF-16, ANSEL, ANSI, Windows-1250, Windows-1251). Если
  буквы вроде _ą_, _ł_, _ö_ или _ß_ выглядят в результате неправильно, выберите другую.
- **Предупреждения** объясняют, что не удалось перенести в точности, — например, дату вида
  _BET 1850 AND 1855_ или дату по юлианскому календарю (старому стилю). Исходный текст
  сохраняется в заметках человека, так что ничего не теряется.
- В разделе **… элемента данных не импортированы** перечислены специфичные для других
  программ сведения, для которых в Family Insight нет места (номера записей, внутренние ID …),
  сгруппированные по тегам.
- Если древо уже открыто, выберите, куда импортировать: **В новое древо** или **В текущее
  древо**. Добавление — это один шаг, который можно отменить.

Фото и документы, на которые ссылается файл, загружаются оттуда, где они находятся по данным
файла, — а если файл пришёл с другого компьютера, то из папки файла `.ged` и её папки `media`.
В файле `.gdz` они находятся внутри.

### Что сохраняется

Имена (включая фамилии при рождении и по мужу), пол, рождение и смерть, события жизни (крещение,
погребение, эмиграция, род занятий, военная служба … и собственные события), заметки,
источники и архивы со ссылками на источники (страница, достоверность, расшифровка), фото
и документы, браки, помолвки и разводы, приёмные и неродные родители и опекуны, а также
координаты мест.

### Переход из другой программы

| Программа                                 | Как экспортировать файл GEDCOM                                                                                                                                |
| ----------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Gramps**                                | **Семейные деревья → Экспорт…**, выберите _GEDCOM_.                                                                                                           |
| **MyHeritage**                            | Family Tree Builder: **Файл → Экспорт в GEDCOM**; на сайте: **Семейное дерево → Управление деревьями → Экспорт в GEDCOM**.                                    |
| **Ancestry**                              | **Trees → (ваше древо) → Tree settings → Export tree** (у Ancestry нет русского интерфейса).                                                                  |
| **FamilySearch**                          | FamilySearch не экспортирует общее древо целиком; свои древа экспортируйте с помощью программ-партнёров или начните с файла GEDCOM, которым кто-то поделился. |
| **Legacy, RootsMagic, Family Tree Maker** | **File → Export → GEDCOM** (в этих программах нет русского интерфейса).                                                                                       |

## Экспорт файла GEDCOM

Выберите **☰ → Экспорт GEDCOM…** (или **Файл → Экспорт → GEDCOM…**):

<Screenshot name="gedcom-export" alt="Окно «Экспорт GEDCOM» с версией GEDCOM 5.5.1 или 7.0 и параметрами «Включить фото и документы», «Скрыть живущих людей» и «Включить заметки»" />

- **Версия** — **5.5.1** читается почти всеми генеалогическими программами; **7.0** — новейшая
  версия.
- **Включить фото и документы** — в версии 5.5.1 они сохраняются в папке `media` рядом с файлом
  GEDCOM; в версии 7.0 всё упаковывается в один файл `.gdz`.
- **Скрыть живущих людей** — заменяет имена людей, которые, возможно, живы, на «Живущий»
  и не включает остальные их данные. Пользуйтесь этим, когда делитесь древом с другими.
- **Включить заметки** — оставьте выключенным, чтобы поделиться только фактами.

::: info Что не передаётся через GEDCOM
Жив ли человек (записывается только смерть), веб-адрес источника (он становится строкой
в заметках источника) и настройки вида вашего древа. Всё остальное вернётся, когда вы снова
импортируете файл в Family Insight.
:::
