# Импорт из CSV

Ваша семья уже записана в таблице? Family Insight может прочитать её из файла **CSV** — этот
формат умеет сохранять любая программа для работы с таблицами.

## 1. Подготовьте таблицу

Отведите **по одной строке на человека** и используйте такие столбцы (в любом порядке,
с английскими или русскими названиями):

| Столбец                      | Русское название                 | Что писать                                                           |
| ---------------------------- | -------------------------------- | -------------------------------------------------------------------- |
| `id` **(обязательно)**       | `id`                             | любая короткая уникальная метка человека, например `p1`, `p2` …      |
| `given_names`                | `имя`                            | имя и отчество                                                       |
| `surname`                    | `фамилия`                        | фамилия                                                              |
| `birth_surname`              | `фамилия_при_рождении`           | фамилия при рождении (девичья)                                       |
| `sex`                        | `пол`                            | `женщина` / `мужчина` (или `ж`, `м`, `female`, `male`)               |
| `birth_date`, `death_date`   | `дата_рождения`, `дата_смерти`   | `1890`, `05.1890`, `12.05.1890`, `~1890` … ([даты](./editing#dates)) |
| `birth_place`, `death_place` | `место_рождения`, `место_смерти` | город или село                                                       |
| `living`                     | `жив`                            | `да` / `нет` (или `yes` / `no`)                                      |
| `father_id`, `mother_id`     | `отец_id`, `мать_id`             | **id** отца и матери                                                 |
| `partner_ids`                | `партнёры_id`                    | **id** партнёров через `\|` — например `p2\|p5`                      |
| `notes`                      | `заметки`                        | всё остальное                                                        |

Принимаются и другие варианты названий — например `имена`, `имя_отчество`, `девичья_фамилия`,
`отец`, `мать`, `супруги`, `примечания`, — а также названия столбцов и значения на **польском,
немецком, французском, испанском, итальянском и португальском** языках (например `imiona`,
`vornamen`, `nom`, `fecha_de_nacimiento`; `kobieta`, `männlich`, `oui`). Все названия перечислены
в [описании формата CSV](/developer/reference/csv-format#columns) (на английском). Как записывать
отчества и двойные фамилии, см. в разделе [имена разных народов](./editing#name-conventions).

Каждому человеку нужен **id** и хотя бы имя или фамилия; все остальные столбцы необязательны.
Родственники связываются через id — например, `p3` с `отец_id` `p1` и `мать_id` `p2` — ребёнок
`p1` и `p2`. Союз достаточно указать только у одного из партнёров.

::: tip Начните с примера
Скачайте пример с 25 людьми — [с английскими названиями столбцов](/samples/example-en.csv) или
[с польскими](/samples/example-pl.csv) — либо пустой шаблон с русскими названиями столбцов
из Family Insight: **Справка → Скачать шаблон CSV…**. Полная спецификация приведена
в [описании формата CSV](/developer/reference/csv-format) (на английском).
:::

## 2. Сохраните таблицу в CSV

| Программа        | Как                                                                              |
| ---------------- | -------------------------------------------------------------------------------- |
| Microsoft Excel  | **Файл → Сохранить как**, тип **CSV UTF-8 (разделитель — запятая) (\*.csv)**     |
| LibreOffice Calc | **Файл → Сохранить как**, тип **Текст CSV (.csv)**, кодировка **Юникод (UTF-8)** |
| Google Таблицы   | **Файл → Скачать → CSV (.csv)**                                                  |

Подходят любые разделители: запятые, точки с запятой и табуляция. Файлы, сохранённые не в UTF-8
(например, обычный тип **CSV** в старых версиях Excel, который с русскими региональными
настройками записывает текст в кодировке Windows-1251 и разделяет столбцы точкой с запятой),
тоже читаются: Family Insight распознаёт кириллицу (Windows-1251), центральноевропейскую
(Windows-1250) и западноевропейскую (Windows-1252) кодировку по буквам.

## 3. Импортируйте

На экране приветствия нажмите **Импорт из CSV…** или, если древо уже открыто, выберите
**☰ → Импорт CSV…**. Можно также перетащить файл `.csv` в окно. Прежде чем что-либо изменится,
вы увидите предпросмотр:

<Screenshot name="csv-import" alt="Предпросмотр импорта: обнаруженные разделитель и кодировка, столбцы с тем, как импортируется каждый из них, предпросмотр первых строк и кнопка «Импортировать»" />

- Вверху — обнаруженные **разделитель и кодировка текста**.
- **Кодировка** — если буквы вроде ж, ё, ä или é выглядят в предпросмотре неправильно,
  выберите здесь другую (показывается для файлов, прочитанных с диска; обнаруженная кодировка
  отмечена).
- **Столбцы** — как будет использован каждый столбец вашего файла. Если столбец не распознан
  (например, потому что он называется «Отчество»), выберите в списке нужное значение или
  **Не импортировать**, чтобы пропустить его.
- **Предпросмотр** — первые строки в том виде, как их понял Family Insight.
- Внизу — сколько людей и связей будет импортировано.

<Screenshot name="csv-import-columns" alt="Таблица «Столбцы»: столбец в файле, «Импортировать как» (список) и значение в первой строке" />

Если древо уже открыто, выберите, куда импортировать: **В новое древо** или **В текущее древо**.
При импорте в текущее древо все люди из файла добавляются как новые (они не сопоставляются
с людьми, которые уже есть в древе), — это один шаг, который можно [отменить](./undo).

Нажмите **Импортировать**. У нового древа из файла CSV ещё нет собственного файла —
[сохраните его](./files), чтобы не потерять.

## Проблемы и предупреждения {#problems}

**Проблемы** (красные) нужно исправить до импорта — исправьте их в таблице (или измените
сопоставление столбцов) и импортируйте снова. **Предупреждения** (жёлтые) объясняют, что
произойдёт; импортировать можно и так. В каждом сообщении указано, к какой строке оно относится.

<Screenshot name="csv-import-errors" alt="Предпросмотр импорта с 2 проблемами: строка 4 — идентификатор p2 встречается несколько раз; строка 5 — ссылка на p9, но строки с таким id нет" />

### Проблемы, которые блокируют импорт

| Сообщение                                                      | Как исправить                                                                                                    |
| -------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------- |
| _Файл пуст._                                                   | Выберите нужный файл или проверьте, что таблица сохранена с данными.                                             |
| _В файле нет столбца «id»…_                                    | Добавьте столбец `id` с уникальной меткой для каждого человека.                                                  |
| _В файле нет столбцов с именем («given_names» или «surname»)._ | Добавьте столбец `given_names` или `surname` (или `имя`, `фамилия`) либо сопоставьте с ним существующий столбец. |
| _В этой строке нет id._                                        | Заполните id в этой строке.                                                                                      |
| _Идентификатор «p2» встречается несколько раз._                | Дайте каждому человеку свой id.                                                                                  |
| _У человека «p7» нет ни имени, ни фамилии._                    | Заполните хотя бы одно из них (или удалите пустую строку).                                                       |
| _Ссылка на «p9», но строки с таким id нет._                    | Исправьте id в `отец_id`, `мать_id` или `партнёры_id` либо добавьте этого человека.                              |
| _Человек ссылается сам на себя («p3»)._                        | Человек не может быть собственным родителем или партнёром — исправьте id.                                        |
| _Отец и мать — один и тот же человек («p1»)._                  | Исправьте `отец_id` или `мать_id`.                                                                               |
| _… оказался(-ась) бы собственным предком._                     | Где-то ребёнок указан родителем собственного предка — проверьте id.                                              |

### Предупреждения

| Сообщение                                                                                | Что произойдёт                                                                                          |
| ---------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------- |
| _Столбец «…» не распознан и будет пропущен._                                             | Столбец пропускается — сопоставьте его с полем, если он нужен.                                          |
| _«…» — непонятная дата; значение добавлено в заметки._                                   | Текст сохраняется в заметках человека, так что ничего не теряется.                                      |
| _«…» — неизвестное значение пола; импортировано как «неизвестен»._                       | Используйте `женщина`, `мужчина`, `другой` или `неизвестно` (или `female`, `male`, `other`, `unknown`). |
| _«…» — не yes/no; статус «в живых» оставлен неизвестным._                                | Используйте `да`/`нет`, `yes`/`no`, `true`/`false` или `1`/`0`.                                         |
| Предупреждения о датах (смерть раньше рождения, старше 120 лет, родитель младше ребёнка) | Импортируется как записано — см. [Предупреждения](./editing#warnings).                                  |

## Что не передаётся через CSV

В CSV сохраняются имена, даты, места, сведения о том, жив ли человек, биологические родители,
партнёры и заметки. **Фото, даты и места союзов, связи с приёмными и неродными родителями
и опекунами, основное лицо и вид древа** есть только в файлах `.finsight` — используйте их,
чтобы сохранить всё.
