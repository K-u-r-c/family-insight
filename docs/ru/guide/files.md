# Сохранение и открытие

## Файл `.finsight`

Каждое родословное древо — это один файл с расширением **`.finsight`**, и внутри него всё: люди,
связи, источники, фото и то, как было показано древо. Вы сами решаете, где он хранится, и можете
копировать его, делать резервные копии или отправлять по электронной почте, как любой другой
документ.

::: info Старые версии
Начиная с версии 1.1 файл `.finsight` — это сжатый пакет (как zip-архив), чтобы фото и сканы
документов хранились экономно: каждая картинка сохраняется только один раз, сколько бы раз она
ни использовалась. Family Insight 1.1 открывает древа из версии 1.0 и сохраняет их в новом
формате; **версия 1.0 не может открыть древа, сохранённые версией 1.1**, — обновите программу на
всех компьютерах, которыми пользуетесь (см. [Установка](./install#updating)).
:::

## Сохранение

| Чтобы                       | Сделайте                                                                                                           |
| --------------------------- | ------------------------------------------------------------------------------------------------------------------ |
| сохранить                   | <kbd>Ctrl</kbd>+<kbd>S</kbd> (<kbd>⌘</kbd>+<kbd>S</kbd>) или **☰ → Сохранить**                                    |
| сохранить под другим именем | <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>S</kbd> (<kbd>⌘</kbd>+<kbd>⇧</kbd>+<kbd>S</kbd>) или **☰ → Сохранить как…** |

При первом сохранении нового древа выберите папку и имя (программа предлагает папку
«Документы» и название древа). Строка состояния внизу всегда показывает, всё ли сохранено:

Если закрыть окно, открыть другое древо или выйти из программы, когда есть несохранённые
изменения, Family Insight спросит, что сделать: **Сохранить**, **Не сохранять** или **Отмена**.

## Автосохранение {#autosave}

Как только древо сохранено в файл, Family Insight автоматически сохраняет его **через 2 секунды
после каждого изменения**. Это можно отключить в [настройках](./settings)
(⚙ → **Сохранять автоматически**); тогда сохраняйте сами с помощью <kbd>Ctrl</kbd>+<kbd>S</kbd>.

Совсем новое древо, которое ещё ни разу не сохранялось, автоматически не сохраняется — сохраните
его один раз, чтобы у него появился файл.

## Восстановление после сбоя {#crash-recovery}

Пока в древе есть несохранённые изменения (например, в новом древе или при выключенном
автосохранении), Family Insight ведёт скрытую копию для восстановления, которая обновляется
через 2 секунды после каждого изменения. Если программа или компьютер аварийно завершат работу,
при следующем запуске программа предложит восстановить эту работу:

<Screenshot name="recovery" alt="Окно «Восстановить несохранённую работу?» со списком, в котором древо Kowalscy, ни разу не сохранялось, и кнопками «Восстановить» и «Отбросить все»" />

Нажмите **Восстановить**, чтобы открыть древо в том виде, в каком оно было, а затем сохраните
его. **Отбросить все** удаляет копии. Копии для восстановления удаляются, как только древо
сохраняется или закрывается обычным образом.

## Резервные копии {#backups}

При каждом сохранении **вручную** (<kbd>Ctrl</kbd>+<kbd>S</kbd> или **Сохранить**) предыдущая
версия файла сохраняется рядом с ним как `имя.finsight.bak1`. Более старые версии сдвигаются
в `.bak2` … `.bak5`, так что последние пять ручных сохранений всегда под рукой. Автосохранение
резервных копий не создаёт.

Чтобы вернуться к более старой версии:

1. Закройте древо в Family Insight.
2. В файловом менеджере найдите папку с древом и сделайте копию нужной резервной копии,
   например `Kowalscy.finsight.bak2`.
3. Переименуйте копию так, чтобы её имя заканчивалось на `.finsight`, например
   `Kowalscy (старая).finsight` (система может спросить, действительно ли вы хотите изменить
   расширение, — подтвердите).
4. Откройте её в Family Insight.

::: tip Не видно расширений?
Windows и macOS по умолчанию скрывают расширения файлов. В Windows в Проводнике выберите
**Вид → Показать → Расширения имён файлов**; в macOS в Finder выберите **Finder → Настройки →
Дополнения → Показывать все расширения имён файлов**.
:::

## Открытие древа {#opening}

- **☰ → Открыть…** или <kbd>Ctrl</kbd>+<kbd>O</kbd> (<kbd>⌘</kbd>+<kbd>O</kbd>), либо
  **Открыть древо…** на экране приветствия;
- **двойной щелчок** по файлу `.finsight` (после установки с помощью установщика Windows,
  программы для macOS или пакета `.deb`);
- **перетаскивание** файла `.finsight` в окно Family Insight — если перетащить файл `.csv`,
  начнётся [импорт CSV](./csv-import);
- **Файл → Открыть недавние** в строке меню или список **Недавние** на экране приветствия.

<Screenshot name="welcome-recent" alt="Экран приветствия со списком «Недавние»: одно древо открыто 2 часа назад, другое зачёркнуто с пометкой «Файл не найден»" />

Перемещённые или удалённые файлы в списке недавних зачёркнуты; уберите их кнопкой **×**.

Если файл не удаётся открыть, Family Insight объяснит почему — например, что он сохранён более
новой версией (обновите программу, см. [Установка](./install#updating)) или что он повреждён
(попробуйте [резервную копию](#backups)).

## Перенос древа на другой компьютер

Скопируйте файл `.finsight` — на флешку, по электронной почте или через облачную папку — и откройте
его в Family Insight на другом компьютере. Фото находятся внутри файла, поэтому больше ничего
не нужно.

::: warning Работа с одним древом в двух местах
Family Insight не объединяет изменения. Если древо хранится в общей или синхронизируемой папке,
открывайте его одновременно только на одном компьютере.
:::
