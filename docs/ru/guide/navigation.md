# Навигация по древу

## Мышью или сенсорной панелью

- **Перемещайте** древо, перетаскивая его за пустое место.
- **Меняйте масштаб** колёсиком мыши (или двумя пальцами на сенсорной панели); точка под
  указателем при этом остаётся на месте. Жест сведения пальцев на сенсорной панели меняет
  масштаб быстрее.
- **Щёлкните** по карточке, чтобы выбрать человека, **дважды щёлкните**, чтобы изменить его
  данные, и **щёлкните правой кнопкой**, чтобы увидеть другие действия. Щелчок по пустому месту
  древа снимает выделение.

Если выбрать человека, который находится за пределами видимой области, — например, в списке
людей, — древо сдвинется так, чтобы его показать.

## Кнопки масштаба и обзорная карта

Кнопки в правом нижнем углу:

<Screenshot name="canvas-controls" alt="Кнопки масштаба: 1 уменьшить, 2 текущий масштаб (щелчок — 100 %), 3 увеличить, 4 вписать в экран, 5 центрировать на выбранном человеке, 6 показать или скрыть обзорную карту" />

1. **Уменьшить**
2. **Текущий масштаб** — щёлкните, чтобы вернуться к 100 %.
3. **Увеличить**
4. **Вписать в экран** — показывает всё древо.
5. **Центрировать на выбранном человеке**
6. **Обзорная карта** — показывает или скрывает маленькую карту в левом нижнем углу. На карте
   видно всё древо, а видимая часть обведена рамкой; щёлкните или перетащите в ней, чтобы
   перейти в другое место.

## Сворачивание ветвей {#collapse}

Большие древа легче читать, если скрыть ветви, с которыми вы сейчас не работаете. Наведите
указатель на карточку человека, у которого есть дети, и нажмите маленькую кнопку **−** под ней,
чтобы скрыть всех его потомков; **+** снова показывает их.

<Screenshot name="collapse-branch" alt="Карточка Tadeusz Wiśniewski с маленькой кнопкой под ней (1), которая скрывает его потомков" />

Свёрнутые ветви сохраняются в файле вместе с [режимом просмотра](./view-modes).

## С клавиатуры {#keyboard}

Щёлкните по древу (или нажимайте <kbd>Tab</kbd>, пока не появится ссылка **Перейти к родословному
древу**, и нажмите <kbd>Enter</kbd>), а затем:

| Клавиша                     | Действие                             |
| --------------------------- | ------------------------------------ |
| <kbd>↑</kbd>                | перейти к родителю                   |
| <kbd>↓</kbd>                | перейти к ребёнку                    |
| <kbd>←</kbd> / <kbd>→</kbd> | перейти к партнёру, брату или сестре |
| <kbd>Enter</kbd>            | изменить данные выбранного человека  |
| <kbd>F</kbd>                | вписать всё древо в экран            |
| <kbd>+</kbd> / <kbd>−</kbd> | увеличить / уменьшить                |
| <kbd>0</kbd>                | масштаб 100 %                        |
| <kbd>Esc</kbd>              | снять выделение                      |

Первое нажатие клавиши со стрелкой выбирает [основное лицо](./view-modes#root-person) (или
первого человека). Все сочетания клавиш перечислены в разделе [Сочетания клавиш](./shortcuts).

::: info Программы чтения с экрана
Древо работает с программами чтения с экрана: у каждой карточки есть подпись с именем и датами,
а при перемещении клавишами со стрелками программа называет человека и его ближайших
родственников.
:::
