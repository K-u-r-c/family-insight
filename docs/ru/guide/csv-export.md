# Экспорт в CSV

Выберите **☰ → Экспорт CSV…** (или **Файл → Экспорт → CSV…** в строке меню):

<Screenshot name="csv-export" alt="Диалог «Экспорт в CSV» с разделителем столбцов (запятая или точка с запятой) и названиями столбцов (English, Polski, Deutsch, Français, Español, Italiano, Português или Русский)" />

1. **Разделитель столбцов** — **Запятая ( , )** для большинства программ; **Точка с запятой ( ; )**
   для Excel с региональными настройками, в которых дробная часть отделяется запятой (русские,
   польские, немецкие, французские, испанские, итальянские, португальские …), — иначе Excel
   помещает всё в один столбец. По умолчанию разделитель выбирается по языку программы,
   и Family Insight запоминает ваш выбор.
2. **Названия столбцов** — на одном из языков программы: русском (`имя`, `фамилия` …), английском
   (`given_names`, `surname` …), польском (`imiona`, `nazwisko` …) и так далее. Значения следуют
   за названиями столбцов (`женщина`, `да` / `нет` по-русски; `female`, `true` / `false`
   по-английски).
3. Нажмите **Экспорт…** и выберите, куда сохранить файл. Когда всё будет готово, появится
   сообщение с кнопкой **Показать в папке**.

Файл записывается в кодировке UTF-8 с меткой порядка байтов (BOM), поэтому кириллица
и другие буквы (ж, ё, ą, ö …) правильно отображаются, если открыть файл в Excel двойным щелчком.

## Что экспортируется

По одной строке на человека, в порядке дат рождения, со столбцами: id, имя и отчество, фамилия,
фамилия при рождении, пол, дата и место рождения, дата и место смерти, жив ли человек, отец и мать
(по id), партнёры (id через `|`) и заметки. Люди получают короткие id `p1`, `p2` …, чтобы файл
было легко читать и редактировать.

**Не экспортируются:** фото, даты и места союзов, связи с приёмными и неродными родителями
и опекунами, основное лицо и вид древа. Храните файл `.finsight` как основную копию — CSV нужен
для работы с таблицами.

Файл можно отредактировать и [импортировать обратно](./csv-import). Точный формат описан
в [описании формата CSV](/developer/reference/csv-format) (на английском).

## Открытие файла в программе для таблиц

| Программа        | Совет                                                                                                                    |
| ---------------- | ------------------------------------------------------------------------------------------------------------------------ |
| Microsoft Excel  | Дважды щёлкните по файлу. Если все данные оказались в столбце A, экспортируйте снова с разделителем **точка с запятой**. |
| LibreOffice Calc | Откройте файл; в окне импорта выберите **UTF-8** и тот разделитель, с которым вы экспортировали.                         |
| Google Таблицы   | **Файл → Импортировать → Загрузка**; разделитель определяется автоматически.                                             |
