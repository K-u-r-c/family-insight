# Сочетания клавиш

В программе нажмите <kbd>?</kbd> или <kbd>F1</kbd> (или выберите **Справка → Сочетания клавиш**),
чтобы увидеть этот список:

<Screenshot name="shortcuts" alt="Окно «Сочетания клавиш» с группами «Файлы», «Правка», «Родословное древо» и «Общие»" />

<ShortcutTable />

Клавиши группы **Родословное древо** работают, когда фокус клавиатуры находится на древе, —
сначала щёлкните по древу или см. раздел [Навигация с клавиатуры](./navigation#keyboard).

## Ещё в строке меню

| Действие              | Windows / Linux                                             | macOS                                               |
| --------------------- | ----------------------------------------------------------- | --------------------------------------------------- |
| Увеличить / уменьшить | <kbd>Ctrl</kbd>+<kbd>=</kbd> / <kbd>Ctrl</kbd>+<kbd>-</kbd> | <kbd>⌘</kbd><kbd>=</kbd> / <kbd>⌘</kbd><kbd>-</kbd> |
| Масштаб 100 %         | <kbd>Ctrl</kbd>+<kbd>0</kbd>                                | <kbd>⌘</kbd><kbd>0</kbd>                            |
| Полноэкранный режим   | <kbd>F11</kbd>                                              | <kbd>⌃</kbd><kbd>⌘</kbd><kbd>F</kbd>                |

В строке меню сочетание клавиш также указано рядом с каждой командой.
