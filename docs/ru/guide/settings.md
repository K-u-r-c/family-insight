# Настройки

Нажмите кнопку **Настройки** (⚙) справа на панели инструментов:

<Screenshot name="settings-menu" alt="Меню настроек: Тема (Системная, Светлая, Тёмная), Стиль (Современный, Гобелен), Язык (English, Polski, Deutsch, Français, Español, Italiano, Português, Русский), Карточки (Просторные, Компактные) и «Сохранять автоматически»" />

| Настройка                              | Варианты                                                                  | Что делает                                                                                                                                          |
| -------------------------------------- | ------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Тема**                               | Системная, Светлая, Тёмная                                                | Цвета программы. **Системная** следует светлому или тёмному режиму компьютера.                                                                      |
| **Стиль**                              | Современный, Гобелен                                                      | Внешний вид всей программы. **Гобелен** напоминает старинный семейный гобелен: пергамент и чернила в светлой теме, тёмно-зелёный и золото в тёмной. |
| **Язык**                               | English, Polski, Deutsch, Français, Español, Italiano, Português, Русский | Язык всей программы, включая строку меню и диалоги. Меняется сразу.                                                                                 |
| **Карточки**                           | Просторные, Компактные                                                    | Размер карточек в древе. Компактные карточки позволяют уместить больше людей на экране и на бумаге.                                                 |
| **Сохранять автоматически**            | вкл. (по умолчанию) / выкл.                                               | [Автосохранение](./files#autosave) древ, у которых уже есть файл.                                                                                   |
| **Проверять обновления автоматически** | вкл. (по умолчанию) / выкл.                                               | Ежедневная проверка новых версий ([Обновления](./updates)); **Проверить сейчас…** проверяет немедленно.                                             |
| **Загружать карты из интернета**       | выкл. (по умолчанию) / вкл.                                               | Загружает подложку карты из OpenStreetMap, пока вы пользуетесь [картой](./map#online).                                                              |
| **Искать места в интернете**           | выкл. (по умолчанию) / вкл.                                               | Позволяет кнопке **Найти в интернете** отправлять название места в OpenStreetMap, чтобы найти его координаты ([Места](./places#lookup)).            |

Стиль можно изменить и в строке меню: **Вид → Стиль**. В стиле «Гобелен» люди на древе — это медальоны в рамке с портретом над именем, партнёров соединяет маленький узел, а линии похожи на золотую нить.

Тему и язык можно также изменить на экране приветствия (в правом верхнем углу) и в меню **Вид**
строки меню. В меню **Вид** также можно показать или скрыть список людей и обзорную карту.

Family Insight запоминает и другое: размер и положение окна, ширину панелей, последний
использованный разделитель CSV и [недавние файлы](./files#opening).

::: tip Разделитель CSV зависит от языка
Когда вы меняете язык в меню **Вид**, вместе с ним меняется и разделитель CSV по умолчанию —
точка с запятой для русского, запятая для английского. При [экспорте](./csv-export) всегда можно
выбрать другой.
:::

## Где хранятся настройки

Настройки сохраняются в небольшом файле `settings.json` в вашем профиле пользователя — отдельно
от ваших древ:

| Система | Папка                                          |
| ------- | ---------------------------------------------- |
| Windows | `%APPDATA%\Family Insight`                     |
| macOS   | `~/Library/Application Support/Family Insight` |
| Linux   | `~/.config/Family Insight`                     |

## Сброс настроек

Закройте Family Insight и удалите `settings.json` из этой папки. При следующем запуске будут
использоваться настройки по умолчанию (и язык вашей системы). Ваши древа это не затронет.
