# Установка

Family Insight распространяется бесплатно. Скачайте программу со
[страницы выпусков на GitHub](https://github.com/K-u-r-c/family-insight/releases/latest): в разделе
**Assets** выберите файл для своей системы.

## Какой файл скачать? {#which-file}

| Ваш компьютер                                | Файл                                                 |
| -------------------------------------------- | ---------------------------------------------------- |
| Windows 10 или 11                            | `family-insight-<version>-setup.exe` (рекомендуется) |
| Windows, без установки                       | `family-insight-<version>-portable.exe`              |
| Mac с Apple Silicon (M1, M2, M3, M4 …)       | `family-insight-<version>-mac-arm64.dmg`             |
| Mac с процессором Intel                      | `family-insight-<version>-mac-x64.dmg`               |
| Linux (любой дистрибутив)                    | `family-insight-<version>-linux-x86_64.AppImage`     |
| Ubuntu, Debian, Linux Mint и другие с `.deb` | `family-insight-<version>-linux-amd64.deb`           |

::: tip Какой у меня Mac?
Откройте меню Apple → **Об этом Mac**. Если там написано **Чип: Apple M…**, берите `mac-arm64`.
Если написано **Процессор: … Intel**, берите `mac-x64`.
:::

::: info Почему система выдаёт предупреждение?
Family Insight пока не подписан платным сертификатом разработчика, поэтому Windows и macOS
не узнают издателя и просят подтвердить первый запуск. Ниже показано, как это сделать. Сама
программа — с открытым исходным кодом: любой может проверить, что она делает.
:::

## Windows

### Установщик (рекомендуется)

1. Скачайте `family-insight-<version>-setup.exe` и откройте его.
2. Если появится синее окно **Система Windows защитила ваш компьютер** (SmartScreen), нажмите
   **Подробнее**, а затем **Выполнить в любом случае**.
3. Выберите язык установщика (English, Polski, Deutsch, Français, Español, Italiano, Português
   или Русский) и следуйте указаниям. Папку установки можно изменить. Права администратора
   не нужны — программа устанавливается для вашей учётной записи.
4. Запустите Family Insight из меню **Пуск** или с помощью **ярлыка на рабочем столе**.

После установки файл `.finsight` открывается в Family Insight двойным щелчком.

### Переносная версия

`family-insight-<version>-portable.exe` работает без установки — например, с флешки. Скачайте
файл и дважды щёлкните по нему (подтвердите запуск в SmartScreen, как описано выше). Настройки
всё равно хранятся в вашем профиле пользователя (см. [Удаление](#uninstalling)); переносная
версия не связывает с собой файлы `.finsight`.

## macOS

1. Скачайте файл `.dmg` для своего Mac (см. таблицу выше) и откройте его.
2. В открывшемся окне перетащите **Family Insight** в папку **Программы**.
3. Откройте **Программы**, **щёлкните правой кнопкой** (или с нажатой клавишей Control)
   по **Family Insight** и выберите **Открыть**, затем ещё раз **Открыть** в диалоговом окне.
   Это нужно сделать только при первом запуске.

::: warning Если macOS не предлагает «Открыть»
В новых версиях macOS откройте **Системные настройки → Конфиденциальность и безопасность**,
прокрутите вниз до сообщения о Family Insight и нажмите **Всё равно открыть**.

Если macOS сообщает, что программа **«повреждена, и её не удаётся открыть»**, откройте программу
**Терминал**, один раз выполните эту команду и снова запустите Family Insight:

```sh
xattr -cr "/Applications/Family Insight.app"
```

:::

## Linux

### AppImage (любой дистрибутив)

AppImage — это один файл, который работает без установки.

1. Скачайте `family-insight-<version>-linux-x86_64.AppImage`.
2. Сделайте его исполняемым: в файловом менеджере откройте **Свойства → Права** и разрешите
   запуск файла как программы или выполните в терминале:

   ```sh
   chmod +x family-insight-*.AppImage
   ```

3. Дважды щёлкните по файлу или выполните `./family-insight-<version>-linux-x86_64.AppImage`.

Для AppImage нужен **FUSE 2**. В большинстве дистрибутивов он уже есть; в Ubuntu 22.04
установите его командой `sudo apt install libfuse2` (в Ubuntu 24.04 и новее:
`sudo apt install libfuse2t64`). Если программа не запускается, см.
[Решение проблем](./troubleshooting#linux).

::: tip Пункт меню для AppImage
AppImage не добавляет себя в меню приложений. Это могут сделать за вас такие инструменты,
как **Gear Lever** или **AppImageLauncher**; можно также установить пакет `.deb` (см. ниже).
:::

### Пакет Debian (Ubuntu, Debian, Linux Mint …)

```sh
sudo apt install ./family-insight-<version>-linux-amd64.deb
```

Пакет добавляет **Family Insight** в меню приложений (категория «Офис») и открывает файлы
`.finsight` двойным щелчком. Из терминала программа запускается командой `family-insight`.

## Обновление {#updating}

Family Insight пока не обновляется сам. Чтобы получить новую версию, скачайте её со
[страницы выпусков](https://github.com/K-u-r-c/family-insight/releases/latest) и установите
так же, как раньше: поверх старой (установщик Windows, `.deb`), заменив программу в папке
«Программы» (macOS) или заменив старый файл AppImage. Ваши древа — это отдельные файлы,
их это не затрагивает; настройки сохраняются.

## Удаление {#uninstalling}

| Система              | Как удалить                                                                      |
| -------------------- | -------------------------------------------------------------------------------- |
| Windows              | **Параметры → Приложения → Установленные приложения → Family Insight → Удалить** |
| Windows (переносная) | Удалите файл `.exe`                                                              |
| macOS                | Перетащите **Family Insight** из папки «Программы» в Корзину                     |
| Linux (AppImage)     | Удалите файл `.AppImage`                                                         |
| Linux (`.deb`)       | `sudo apt remove family-insight`                                                 |

При удалении программы ваши файлы `.finsight` никогда не удаляются. Настройки, список
недавних файлов и копии для восстановления после сбоя остаются в папке вашего профиля
пользователя; удалите и её, если хотите убрать всё:

| Система | Папка настроек                                 |
| ------- | ---------------------------------------------- |
| Windows | `%APPDATA%\Family Insight`                     |
| macOS   | `~/Library/Application Support/Family Insight` |
| Linux   | `~/.config/Family Insight`                     |
