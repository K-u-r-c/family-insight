# Карта

Карта показывает, **где жила ваша семья**: каждое рождение, смерть, брак и событие жизни
в месте, у которого есть [координаты](./places). Переключайтесь между древом и картой кнопками
рядом с режимами просмотра на панели инструментов (или командой **Вид → Карта**,
<kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>M</kbd>).

## Как читать карту

- Каждая **метка** — это место; число показывает, у скольких людей там есть какой-либо факт.
  При мелком масштабе близкие места объединяются в кружок с числом — увеличьте карту, чтобы
  их разделить.
- **Цвет** обозначает поколение, отсчитанное от основного лица древа: тёплые цвета — для более
  ранних поколений, холодные — для более поздних, серый — для поколения самого основного лица (3).
- **Щёлкните по метке** (2) — или выберите её клавишей <kbd>Tab</kbd> и нажмите <kbd>Enter</kbd>, —
  чтобы увидеть всех, у кого там есть факт. Щёлкните по имени, чтобы выбрать человека: откроются
  подробности, а **пунктирная линия** покажет места его жизни по порядку (рождение, события
  по дате, смерть).
- **Масштаб** меняется колёсиком мыши или кнопками **+**/**−**; перетаскивайте карту, чтобы
  перемещаться.

## Фильтры

- **Показать** (1) — рождения, смерти, браки и другие события жизни в любом сочетании.
- **Период** — перетащите два ползунка, чтобы показать только факты между двумя годами. Пока
  задан период, факты без даты скрыты.

## Места без координат

Под фильтрами Family Insight перечисляет места, у которых ещё нет координат. Кнопка **Указать
координаты** открывает их в окне [Места](./places), где можно найти координаты в интернете или
ввести их вручную.

## Карты из интернета {#online}

Подложка карты — улицы, реки, границы — загружается из
[OpenStreetMap](https://www.openstreetmap.org) через интернет. Она **выключена, пока вы её
не разрешите**:

<Screenshot name="map-offline" alt="Сообщение о том, что подложка карты загружается из OpenStreetMap через интернет и сейчас выключена, с кнопкой «Загружать карты из интернета»" />

- Нажмите **Загружать карты из интернета** и подтвердите. Загружается только та область карты,
  которую вы смотрите, — никаких имён или других данных из вашего древа. Фрагменты карты
  хранятся на вашем компьютере неделю.
- Без подложки или без подключения к интернету метки, фильтры и списки по-прежнему работают
  на простом фоне.
- Эту возможность можно снова отключить в настройках (**⚙ → Загружать карты из интернета**).

## Экспорт

**Экспорт карты в PNG…** сохраняет карту такой, какой вы её видите, — с метками, выбранным путём
и указанием авторства OpenStreetMap — в виде изображения.
