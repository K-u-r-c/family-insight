# Updates

Family Insight checks once a day whether a new version is available. Only the app's version is
sent to GitHub, where the releases are published – none of your data.

## When a new version is available

A notice appears in the bottom-right corner:

<Screenshot name="update-available" alt="The notice Family Insight 1.2.0 is available with the buttons Download, Release notes, Later and Skip this version" />

- **Download** – downloads the update in the background; a progress bar shows how far it is.
- **Release notes** – what's new in this version.
- **Later** – hides the notice until the next start.
- **Skip this version** – no more reminders about this version (the next one will be offered).

<Screenshot name="update-notes" alt="The window What's new in 1.2.0 with headings and a list of the changes" />

When the download is finished, choose **Restart now** – Family Insight asks you to save unsaved
changes first, then restarts in the new version. **When I quit** installs it the next time you
close the program.

::: info Portable, deb and macOS versions
The portable Windows program, the deb package for Linux and the macOS app can't replace
themselves. For them, **Download page** opens the release page, where you download the new
version as usual (see [Installation](./install#updating)).
:::

## Check now, or switch checks off

In the settings menu (**⚙**, top right):

- **Check for updates automatically** – on by default; switch it off if you prefer to update by
  hand.
- **Check now…** – checks right away and tells you if you already have the newest version. The
  time of the last check is shown next to it.

**Check for Updates…** is also in the **Help** menu (on macOS in the **Family Insight** menu).
