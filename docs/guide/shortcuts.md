# Keyboard shortcuts

In the program, press <kbd>?</kbd> or <kbd>F1</kbd> (or choose **Help → Keyboard Shortcuts**) to see
this list:

<Screenshot name="shortcuts" alt="The Keyboard shortcuts window with the groups Files, Editing, Family tree and General" />

<ShortcutTable />

The keys in the **Family tree** group work when the tree has the keyboard focus – click the tree
first, or see [Navigating with the keyboard](./navigation#keyboard).

## More in the menu bar

| Action        | Windows / Linux                                             | macOS                                               |
| ------------- | ----------------------------------------------------------- | --------------------------------------------------- |
| Zoom in / out | <kbd>Ctrl</kbd>+<kbd>=</kbd> / <kbd>Ctrl</kbd>+<kbd>-</kbd> | <kbd>⌘</kbd><kbd>=</kbd> / <kbd>⌘</kbd><kbd>-</kbd> |
| Zoom to 100 % | <kbd>Ctrl</kbd>+<kbd>0</kbd>                                | <kbd>⌘</kbd><kbd>0</kbd>                            |
| Full screen   | <kbd>F11</kbd>                                              | <kbd>⌃</kbd><kbd>⌘</kbd><kbd>F</kbd>                |

The menu bar also shows the shortcut next to each command.
