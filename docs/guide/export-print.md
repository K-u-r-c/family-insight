# Images, PDF and printing

## Export an image or a PDF

Choose **☰ → Export Image…** (or **File → Export → Image (PNG, SVG, PDF)…** in the menu bar):

<Screenshot name="export-image" alt="The Export image dialog with the format (PNG, SVG, PDF), what to export (whole tree or visible area), the resolution and the option to add the tree name and today's date" />

- **Format**
  - **PNG** – a picture for sharing, e-mail or presentations.
  - **SVG** – a sharp vector image you can scale to any size or edit (for example in Inkscape).
  - **PDF** – a printable document; the tree is scaled to fit on **one page**.
- **What to export** – the **whole tree** or only the **visible area** (what you see on the
  screen now – zoom and move the tree first).
- **Resolution** (PNG) – 1×, 2× or 3×. Higher means a sharper but larger file.
- **Paper size** and **orientation** (PDF) – A4, A3 or Letter, landscape or portrait.
- **Add the tree name and today's date** – a title at the top.

Click **Export…** and choose where to save the file.

Exports always use the **light** colours, which print well, even when you use the dark theme. The
[view mode](./view-modes) and [collapsed branches](./navigation#collapse) are respected, so you can
export only someone's ancestors, for example.

## Print

Choose **☰ → Print…** or press <kbd>Ctrl</kbd>+<kbd>P</kbd> (<kbd>⌘</kbd>+<kbd>P</kbd>). Your system's
print window opens with the whole tree on an A4 landscape page, with the tree name and date. Choose
the printer and paper there.

## Tips for large trees

- On one page a big tree gets very small. Print parts of it instead: switch to the **Ancestors**
  or **Descendants** view with a few [generations](./view-modes#generations), or
  [collapse branches](./navigation#collapse).
- Choose **A3** for a PDF, or export a **PNG at 3×** or an **SVG** and print it in a print shop as a
  poster.
- Use the **compact cards** ([settings](./settings)) to fit more people.
