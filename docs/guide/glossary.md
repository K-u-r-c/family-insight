# Glossary

| Term                 | Polish                | Meaning                                                                                                          |
| -------------------- | --------------------- | ---------------------------------------------------------------------------------------------------------------- |
| **Ancestors**        | Przodkowie            | A person's parents, grandparents, great-grandparents and so on; also the [view mode](./view-modes) showing them. |
| **Birth surname**    | Nazwisko rodowe       | The surname a person was born with (maiden name), shown as “née …”.                                              |
| **Card**             | Karta                 | The box representing one person in the tree.                                                                     |
| **CSV**              | CSV                   | A plain-text spreadsheet format used to [import](./csv-import) and [export](./csv-export) people.                |
| **Descendants**      | Potomkowie            | A person's children, grandchildren and so on; also the view mode showing them.                                   |
| **Details panel**    | Panel szczegółów      | The panel on the right with the selected person's data, family and timeline.                                     |
| **Generation**       | Pokolenie             | One level of the tree: parents are one generation above their children.                                          |
| **Half-sibling**     | Rodzeństwo przyrodnie | A brother or sister who shares only one parent.                                                                  |
| **Hourglass**        | Klepsydra             | A view with a person's ancestors above and descendants below – shaped like an hourglass.                         |
| **Overview map**     | Mapa przeglądowa      | The small map of the whole tree in the bottom-left corner (minimap).                                             |
| **Partnership**      | Związek               | A relationship between two partners: marriage, partnership, engagement or living together.                       |
| **Qualifier**        | Dokładność daty       | Whether a date is exact, _about_, _before_ or _after_ (`~`, `<`, `>`).                                           |
| **Root person**      | Osoba główna          | The person the ancestor and descendant views start from, marked 🏠.                                              |
| **Step-parent**      | Rodzic przybrany      | A parent by marriage rather than by birth; adoptive and foster parents are recorded similarly.                   |
| **`.finsight` file** | Plik `.finsight`      | The file in which Family Insight saves a whole tree, including photos.                                           |
| **Timeline**         | Oś życia              | The list of life events (birth, marriages, children, death) in the details panel.                                |
