# Słowniczek

| Pojęcie                   | Po angielsku     | Znaczenie                                                                                                    |
| ------------------------- | ---------------- | ------------------------------------------------------------------------------------------------------------ |
| **CSV**                   | CSV              | Tekstowy format arkusza służący do [importu](./csv-import) i [eksportu](./csv-export) osób.                  |
| **Dokładność daty**       | Qualifier        | Czy data jest dokładna, _około_, _przed_ czy _po_ (`~`, `<`, `>`).                                           |
| **Karta**                 | Card             | Prostokąt przedstawiający jedną osobę w drzewie.                                                             |
| **Klepsydra**             | Hourglass        | Widok z przodkami osoby nad nią i potomkami pod nią – w kształcie klepsydry.                                 |
| **Mapa przeglądowa**      | Overview map     | Mała mapa całego drzewa w lewym dolnym rogu (minimapa).                                                      |
| **Nazwisko rodowe**       | Birth surname    | Nazwisko z urodzenia (panieńskie), pokazywane jako „z d. …”.                                                 |
| **Osoba główna**          | Root person      | Osoba, od której zaczynają się widoki przodków i potomków, oznaczona 🏠.                                     |
| **Oś życia**              | Timeline         | Lista wydarzeń z życia (urodzenie, śluby, dzieci, śmierć) w panelu szczegółów.                               |
| **Panel szczegółów**      | Details panel    | Panel po prawej z danymi, rodziną i osią życia wybranej osoby.                                               |
| **Plik `.finsight`**      | `.finsight` file | Plik, w którym Family Insight zapisuje całe drzewo, razem ze zdjęciami.                                      |
| **Pokolenie**             | Generation       | Jeden poziom drzewa: rodzice są pokolenie wyżej niż ich dzieci.                                              |
| **Potomkowie**            | Descendants      | Dzieci, wnuki, prawnuki osoby i tak dalej; także tryb widoku, który ich pokazuje.                            |
| **Przodkowie**            | Ancestors        | Rodzice, dziadkowie, pradziadkowie osoby i tak dalej; także [tryb widoku](./view-modes), który ich pokazuje. |
| **Rodzeństwo przyrodnie** | Half-sibling     | Brat lub siostra, z którymi łączy tylko jeden wspólny rodzic.                                                |
| **Rodzic przybrany**      | Step-parent      | Rodzic przez małżeństwo, a nie z urodzenia; podobnie zapisuje się rodziców adopcyjnych i zastępczych.        |
| **Związek**               | Partnership      | Relacja dwojga partnerów: małżeństwo, związek, zaręczyny lub wspólne życie.                                  |
