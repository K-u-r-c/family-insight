# Skróty klawiszowe

W programie naciśnij <kbd>?</kbd> lub <kbd>F1</kbd> (albo wybierz **Pomoc → Skróty klawiszowe**),
aby zobaczyć tę listę:

<Screenshot name="shortcuts" alt="Okno Skróty klawiszowe z grupami Pliki, Edycja, Drzewo i Ogólne" />

<ShortcutTable />

Klawisze z grupy **Drzewo** działają, gdy drzewo jest aktywne – najpierw kliknij drzewo albo
zobacz [Poruszanie się klawiaturą](./navigation#keyboard).

## Więcej w pasku menu

| Działanie            | Windows / Linux                                             | macOS                                               |
| -------------------- | ----------------------------------------------------------- | --------------------------------------------------- |
| Powiększ / pomniejsz | <kbd>Ctrl</kbd>+<kbd>=</kbd> / <kbd>Ctrl</kbd>+<kbd>-</kbd> | <kbd>⌘</kbd><kbd>=</kbd> / <kbd>⌘</kbd><kbd>-</kbd> |
| Powiększenie 100%    | <kbd>Ctrl</kbd>+<kbd>0</kbd>                                | <kbd>⌘</kbd><kbd>0</kbd>                            |
| Pełny ekran          | <kbd>F11</kbd>                                              | <kbd>⌃</kbd><kbd>⌘</kbd><kbd>F</kbd>                |

Pasek menu pokazuje też skrót obok każdego polecenia.
