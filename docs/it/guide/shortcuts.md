# Scorciatoie da tastiera

Nel programma premi <kbd>?</kbd> o <kbd>F1</kbd> (o scegli **Aiuto → Scorciatoie da tastiera**) per
vedere questo elenco:

<Screenshot name="shortcuts" alt="La finestra Scorciatoie da tastiera con i gruppi File, Modifica, Albero genealogico e Generale" />

<ShortcutTable />

I tasti del gruppo **Albero genealogico** funzionano quando l'albero ha il focus della tastiera:
prima fai clic sull'albero, oppure vedi [Muoversi con la tastiera](./navigation#keyboard).

## Altro nella barra dei menu

| Azione               | Windows / Linux                                             | macOS                                               |
| -------------------- | ----------------------------------------------------------- | --------------------------------------------------- |
| Ingrandisci / riduci | <kbd>Ctrl</kbd>+<kbd>=</kbd> / <kbd>Ctrl</kbd>+<kbd>-</kbd> | <kbd>⌘</kbd><kbd>=</kbd> / <kbd>⌘</kbd><kbd>-</kbd> |
| Zoom al 100 %        | <kbd>Ctrl</kbd>+<kbd>0</kbd>                                | <kbd>⌘</kbd><kbd>0</kbd>                            |
| Schermo intero       | <kbd>F11</kbd>                                              | <kbd>⌃</kbd><kbd>⌘</kbd><kbd>F</kbd>                |

La barra dei menu mostra anche la scorciatoia accanto a ogni comando.
