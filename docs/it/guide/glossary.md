# Glossario

| Termine                        | Inglese          | Significato                                                                                                                    |
| ------------------------------ | ---------------- | ------------------------------------------------------------------------------------------------------------------------------ |
| **Antenati**                   | Ancestors        | I genitori, i nonni, i bisnonni e così via di una persona; anche la [modalità di vista](./view-modes) che li mostra.           |
| **Clessidra**                  | Hourglass        | Una vista con gli antenati di una persona sopra e i discendenti sotto, a forma di clessidra.                                   |
| **Cognome di nascita**         | Birth surname    | Il cognome con cui una persona è nata (da nubile), mostrato come “nata …”.                                                     |
| **Cronologia**                 | Timeline         | L'elenco degli eventi della vita (nascita, matrimoni, figli, morte) nel pannello dei dettagli.                                 |
| **CSV**                        | CSV              | Un formato di foglio di calcolo in testo semplice usato per [importare](./csv-import) ed [esportare](./csv-export) le persone. |
| **Discendenti**                | Descendants      | I figli, i nipoti e così via di una persona; anche la modalità di vista che li mostra.                                         |
| **File `.finsight`**           | `.finsight` file | Il file in cui Family Insight salva un intero albero, foto comprese.                                                           |
| **Fratellastro / sorellastra** | Half-sibling     | Un fratello o una sorella con cui si ha in comune un solo genitore.                                                            |
| **Generazione**                | Generation       | Un livello dell'albero: i genitori stanno una generazione sopra i loro figli.                                                  |
| **Genitore acquisito**         | Step-parent      | Un genitore per matrimonio anziché per nascita; i genitori adottivi e affidatari si registrano in modo simile.                 |
| **Mappa d'insieme**            | Overview map     | La piccola mappa di tutto l'albero nell'angolo in basso a sinistra (minimappa).                                                |
| **Pannello dei dettagli**      | Details panel    | Il pannello a destra con i dati, la famiglia e la cronologia della persona selezionata.                                        |
| **Persona principale**         | Root person      | La persona da cui partono le viste degli antenati e dei discendenti, indicata con 🏠.                                          |
| **Precisione della data**      | Qualifier        | Indica se una data è esatta, _circa_, _prima_ o _dopo_ (`~`, `<`, `>`).                                                        |
| **Scheda**                     | Card             | Il riquadro che rappresenta una persona nell'albero.                                                                           |
| **Unione**                     | Partnership      | Una relazione tra due partner: matrimonio, unione, fidanzamento o convivenza.                                                  |
