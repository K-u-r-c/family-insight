# Imágenes, PDF e impresión

## Exportar una imagen o un PDF

Elija **☰ → Exportar imagen…** (o **Archivo → Exportar → Imagen (PNG, SVG, PDF)…** en la barra de
menús):

<Screenshot name="export-image" alt="El diálogo Exportar imagen con el formato (PNG, SVG, PDF), qué exportar (todo el árbol o el área visible), la resolución y la opción de añadir el nombre del árbol y la fecha de hoy" />

- **Formato**
  - **PNG**: una imagen para compartir, enviar por correo electrónico o usar en presentaciones.
  - **SVG**: una imagen vectorial nítida que puede ampliar a cualquier tamaño o editar (por
    ejemplo, en Inkscape).
  - **PDF**: un documento para imprimir; el árbol se ajusta para caber en **una página**.
- **Qué exportar**: **todo el árbol** o solo el **área visible** (lo que ve ahora en la pantalla;
  amplíe y mueva antes el árbol).
- **Resolución** (PNG): 1×, 2× o 3×. Cuanto más alta, más nítido pero más grande es el archivo.
- **Tamaño del papel** y **orientación** (PDF): A4, A3 o Letter (carta), horizontal o vertical.
- **Añadir el nombre del árbol y la fecha de hoy**: un título en la parte superior.

Haga clic en **Exportar…** y elija dónde guardar el archivo.

Las exportaciones siempre usan los colores **claros**, que se imprimen bien, aunque use el tema
oscuro. Se respetan el [modo de vista](./view-modes) y las [ramas contraídas](./navigation#collapse),
de modo que puede exportar, por ejemplo, solo los ascendientes de una persona.

## Imprimir

Elija **☰ → Imprimir…** o pulse <kbd>Ctrl</kbd>+<kbd>P</kbd> (<kbd>⌘</kbd>+<kbd>P</kbd>). Se abre la
ventana de impresión de su sistema con todo el árbol en una página A4 horizontal, con el nombre del
árbol y la fecha. Elija allí la impresora y el papel.

## Consejos para árboles grandes {#large-trees}

- En una sola página, un árbol grande queda muy pequeño. Imprima mejor partes de él: cambie a la
  vista **Ascendientes** o **Descendientes** con pocas [generaciones](./view-modes#generations), o
  [contraiga ramas](./navigation#collapse).
- Elija **A3** para un PDF, o exporte un **PNG a 3×** o un **SVG** e imprímalo como póster en una
  imprenta o copistería.
- Use las **tarjetas compactas** ([configuración](./settings)) para que quepan más personas.
