# Atajos de teclado

En el programa, pulse <kbd>?</kbd> o <kbd>F1</kbd> (o elija **Ayuda → Atajos de teclado**) para ver
esta lista:

<Screenshot name="shortcuts" alt="La ventana Atajos de teclado con los grupos Archivos, Edición, Árbol genealógico y General" />

<ShortcutTable />

Las teclas del grupo **Árbol genealógico** funcionan cuando el árbol tiene el foco del teclado:
haga clic antes en el árbol o consulte [Navegar con el teclado](./navigation#keyboard).

## Más en la barra de menús

| Acción              | Windows / Linux                                             | macOS                                               |
| ------------------- | ----------------------------------------------------------- | --------------------------------------------------- |
| Acercar / alejar    | <kbd>Ctrl</kbd>+<kbd>=</kbd> / <kbd>Ctrl</kbd>+<kbd>-</kbd> | <kbd>⌘</kbd><kbd>=</kbd> / <kbd>⌘</kbd><kbd>-</kbd> |
| Ampliación al 100 % | <kbd>Ctrl</kbd>+<kbd>0</kbd>                                | <kbd>⌘</kbd><kbd>0</kbd>                            |
| Pantalla completa   | <kbd>F11</kbd>                                              | <kbd>⌃</kbd><kbd>⌘</kbd><kbd>F</kbd>                |

La barra de menús también muestra el atajo junto a cada comando.
