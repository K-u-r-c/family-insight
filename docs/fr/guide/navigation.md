# Se déplacer dans l’arbre

## À la souris ou au pavé tactile

- **Déplacez** l’arbre en faisant glisser une partie vide.
- **Zoomez** avec la molette de la souris (ou deux doigts sur un pavé tactile) ; le point situé
  sous le pointeur reste en place. Le pincement sur un pavé tactile zoome plus vite.
- **Cliquez** sur une fiche pour sélectionner la personne, **double-cliquez** pour la modifier,
  faites un **clic droit** pour d’autres actions. Cliquez sur une partie vide de l’arbre pour
  annuler la sélection.

Quand vous sélectionnez une personne située hors de la zone visible – par exemple dans la liste des
personnes –, l’arbre se déplace pour l’afficher.

## Commandes de zoom et carte d’ensemble

Les boutons dans le coin inférieur droit :

<Screenshot name="canvas-controls" alt="Les commandes de zoom : 1 zoom arrière, 2 zoom actuel (cliquer pour 100 %), 3 zoom avant, 4 ajuster à l’écran, 5 centrer sur la personne sélectionnée, 6 afficher ou masquer la carte d’ensemble" />

1. **Zoom arrière**
2. **Zoom actuel** – cliquez dessus pour revenir à 100 %.
3. **Zoom avant**
4. **Ajuster à l’écran** – affiche tout l’arbre.
5. **Centrer sur la personne sélectionnée**
6. **Carte d’ensemble** – affiche ou masque la petite carte dans le coin inférieur gauche. Elle
   montre tout l’arbre avec un cadre autour de la partie que vous voyez ; cliquez ou faites glisser
   dedans pour aller ailleurs.

## Replier des branches {#collapse}

Les grands arbres sont plus lisibles quand vous masquez les branches sur lesquelles vous ne
travaillez pas. Pointez une fiche qui a des enfants et cliquez sur le petit bouton **−** en dessous
pour masquer toute la descendance de cette personne ; **+** l’affiche de nouveau.

<Screenshot name="collapse-branch" alt="La fiche de Tadeusz Wiśniewski avec le petit bouton en dessous (1) qui masque sa descendance" />

Les branches repliées sont enregistrées dans le fichier avec le [mode d’affichage](./view-modes).

## Au clavier {#keyboard}

Cliquez sur l’arbre (ou appuyez sur <kbd>Tab</kbd> jusqu’à ce que le lien
**Aller à l’arbre généalogique** apparaisse, puis sur <kbd>Enter</kbd>), puis :

| Touche                      | Action                                    |
| --------------------------- | ----------------------------------------- |
| <kbd>↑</kbd>                | aller à un parent                         |
| <kbd>↓</kbd>                | aller à un enfant                         |
| <kbd>←</kbd> / <kbd>→</kbd> | aller à un conjoint, un frère ou une sœur |
| <kbd>Enter</kbd>            | modifier la personne sélectionnée         |
| <kbd>F</kbd>                | ajuster tout l’arbre à l’écran            |
| <kbd>+</kbd> / <kbd>−</kbd> | zoom avant / arrière                      |
| <kbd>0</kbd>                | zoom à 100 %                              |
| <kbd>Esc</kbd>              | annuler la sélection                      |

La première pression sur une flèche sélectionne la
[personne de référence](./view-modes#root-person) (ou la première personne). Tous les raccourcis
sont listés dans [Raccourcis clavier](./shortcuts).

::: info Lecteurs d’écran
L’arbre fonctionne avec les lecteurs d’écran : chaque fiche a une étiquette avec le nom et les
dates, et quand vous vous déplacez avec les flèches, le logiciel annonce la personne et ses proches
les plus directs.

:::
