# Sources

Une bonne histoire familiale dit **d’où vient chaque information** : un registre paroissial, un
acte d’état civil, un recensement, une lettre de famille, un entretien avec grand-mère.
Family Insight tient la liste de vos **sources** et vous permet de les **citer** pour chaque fait.

## Citer une source pour un fait {#cite}

1. Sélectionnez la personne et cliquez sur **Modifier**.
2. À côté de **Nom** (les sources sur la personne en général), **Naissance**, **Vie** (le décès) et
   de chaque événement se trouve un petit bouton de source (1). Il indique combien de sources le
   fait possède.

<Screenshot name="cite-buttons" alt="L’éditeur de Jan Kowalski avec un petit bouton de source à côté de Naissance (1) indiquant une source" />

3. Dans la fenêtre qui s’ouvre, choisissez une **source existante** – ou tapez le titre d’une
   **nouvelle source** et cliquez sur **Créer et citer**.
4. Ajoutez les détails de la citation (cliquez sur le crayon pour l’ouvrir) :
   - **Page ou acte** – l’endroit où se trouve l’information dans la source, par exemple _p. 12_
     ou _acte 345_ ;
   - **Fiabilité** – _primaire_ (établie à l’époque, comme un acte de naissance), _secondaire_
     (établie plus tard, comme une chronique familiale), _douteuse_ ou _peu fiable_ ;
   - la **date de l’acte**, une **transcription** du texte tel qu’il est écrit, et des **notes**.

<Screenshot name="citations-dialog" alt="La fenêtre Sources pour la naissance de Jan Kowalski avec une citation : le registre paroissial, acte 345, primaire, avec la transcription de l’acte" />

Les relations peuvent aussi être sourcées : ouvrez le menu **⋯** à côté d’un parent ou d’un
conjoint et choisissez **Sources**. Dans **Modifier l’union**, vous pouvez citer séparément le début
(par exemple l’acte de mariage) et la fin.

## Gérer vos sources

Ouvrez **☰ → Sources…** (ou **Édition → Sources…** dans la barre de menus) :

<Screenshot name="sources-manager" alt="Le gestionnaire de sources : à gauche une liste de sources avec recherche, à droite le registre paroissial sélectionné avec son titre, son dépôt d’archives, sa cote et les faits qui le citent" />

- **Rechercher des sources** et **Nouvelle source** à gauche ; cliquez sur une source pour la
  modifier à droite.
- **Titre**, **Auteur** et **Publication** décrivent la source ; la **Cote** est sa référence dans
  le fonds d’archives.
- **Dépôt d’archives** – l’endroit où la source est conservée : archives, bibliothèque, paroisse,
  site web. Choisissez-en un dans la liste ou ajoutez-en un sous **Nouveau dépôt d’archives**.
- **Numérisations et photos** – joignez des numérisations de la source (pages de registre, actes) ;
  voir [Photos et documents](./media#scans-of-sources).
- **Citée par** liste tous les faits qui citent la source – cliquez sur l’un d’eux pour aller à la
  personne concernée.
- **Supprimer la source** – si la source est citée, Family Insight vous le demande d’abord et
  retire aussi ses citations. Comme toute modification, cela peut être annulé.

## Où voir les sources

- **Détails** – les faits sourcés sont suivis d’un petit nombre (1). Cliquez dessus pour voir les
  citations. En bas, **Sources** liste toutes les sources utilisées pour la personne.

  <Screenshot name="sources-details" alt="Les détails de Jan Kowalski : un repère 1 après Naissance (1) et une liste Sources en bas avec trois sources" />

- La **recherche** trouve les personnes d’après les titres de leurs sources.
- Les **statistiques** indiquent la part des faits qui ont au moins une source – une bonne mesure de
  la qualité de la documentation de votre arbre ([Statistiques](./statistics)).

::: info
Les sources sont enregistrées dans le fichier `.finsight`. Les exports CSV ne les incluent pas.

:::
