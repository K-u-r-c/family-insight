# Raccourcis clavier

Dans le logiciel, appuyez sur <kbd>?</kbd> ou <kbd>F1</kbd> (ou choisissez
**Aide → Raccourcis clavier**) pour afficher cette liste :

<Screenshot name="shortcuts" alt="La fenêtre Raccourcis clavier avec les groupes Fichiers, Modification, Arbre généalogique et Général" />

<ShortcutTable />

Les touches du groupe **Arbre généalogique** fonctionnent quand l’arbre a le focus clavier –
cliquez d’abord sur l’arbre, ou voir [Se déplacer au clavier](./navigation#keyboard).

## Plus de raccourcis dans la barre de menus

| Action               | Windows / Linux                                             | macOS                                               |
| -------------------- | ----------------------------------------------------------- | --------------------------------------------------- |
| Zoom avant / arrière | <kbd>Ctrl</kbd>+<kbd>=</kbd> / <kbd>Ctrl</kbd>+<kbd>-</kbd> | <kbd>⌘</kbd><kbd>=</kbd> / <kbd>⌘</kbd><kbd>-</kbd> |
| Zoom à 100 %         | <kbd>Ctrl</kbd>+<kbd>0</kbd>                                | <kbd>⌘</kbd><kbd>0</kbd>                            |
| Plein écran          | <kbd>F11</kbd>                                              | <kbd>⌃</kbd><kbd>⌘</kbd><kbd>F</kbd>                |

La barre de menus affiche aussi le raccourci à côté de chaque commande.
