# Mises à jour

Family Insight vérifie une fois par jour si une nouvelle version est disponible. Seule la version
de l’application est envoyée à GitHub, où les versions sont publiées – aucune de vos données.

## Quand une nouvelle version est disponible

Un avis apparaît dans le coin inférieur droit :

<Screenshot name="update-available" alt="L’avis Family Insight 1.2.0 est disponible avec les boutons Télécharger, Notes de version, Plus tard et Ignorer cette version" />

- **Télécharger** – télécharge la mise à jour en arrière-plan ; une barre de progression indique où
  en est le téléchargement.
- **Notes de version** – les nouveautés de cette version.
- **Plus tard** – masque l’avis jusqu’au prochain lancement.
- **Ignorer cette version** – plus aucun rappel pour cette version (la suivante sera proposée).

<Screenshot name="update-notes" alt="La fenêtre Nouveautés de la version 1.2.0 avec des titres et une liste des modifications" />

Une fois le téléchargement terminé, choisissez **Redémarrer maintenant** – Family Insight vous
demande d’abord d’enregistrer les modifications en cours, puis redémarre dans la nouvelle version.
**À la fermeture** l’installe la prochaine fois que vous fermez le logiciel.

::: info Versions portable, deb et macOS
Le logiciel portable pour Windows, le paquet deb pour Linux et l’application macOS ne peuvent pas
se remplacer eux-mêmes. Pour eux, **Page de téléchargement** ouvre la page de la version, où vous
téléchargez la nouvelle version comme d’habitude (voir [Installation](./install#updating)).

:::

## Vérifier maintenant, ou désactiver la vérification

Dans le menu des paramètres (**⚙**, en haut à droite) :

- **Rechercher automatiquement les mises à jour** – activé par défaut ; désactivez-le si vous
  préférez faire les mises à jour vous-même.
- **Rechercher maintenant…** – vérifie tout de suite et vous indique si vous avez déjà la version
  la plus récente. L’heure de la dernière vérification est affichée à côté.

**Rechercher des mises à jour…** se trouve aussi dans le menu **Aide** (sur macOS, dans le menu
**Family Insight**).
