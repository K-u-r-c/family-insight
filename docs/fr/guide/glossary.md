# Glossaire

| Terme                     | Anglais          | Signification                                                                                                                                     |
| ------------------------- | ---------------- | ------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Ascendance**            | Ancestors        | Les parents, grands-parents, arrière-grands-parents d’une personne, et ainsi de suite ; aussi le [mode d’affichage](./view-modes) qui les montre. |
| **Carte d’ensemble**      | Overview map     | La petite carte de tout l’arbre dans le coin inférieur gauche (minicarte).                                                                        |
| **Chronologie**           | Timeline         | La liste des événements d’une vie (naissance, mariages, enfants, décès) dans le panneau de détails.                                               |
| **CSV**                   | CSV              | Un format de tableur en texte brut, utilisé pour [importer](./csv-import) et [exporter](./csv-export) des personnes.                              |
| **Demi-frère, demi-sœur** | Half-sibling     | Un frère ou une sœur qui n’a qu’un parent en commun.                                                                                              |
| **Descendance**           | Descendants      | Les enfants, petits-enfants d’une personne, et ainsi de suite ; aussi le mode d’affichage qui les montre.                                         |
| **Fiche**                 | Card             | Le cadre qui représente une personne dans l’arbre.                                                                                                |
| **Fichier `.finsight`**   | `.finsight` file | Le fichier dans lequel Family Insight enregistre un arbre entier, photos comprises.                                                               |
| **Génération**            | Generation       | Un niveau de l’arbre : les parents sont une génération au-dessus de leurs enfants.                                                                |
| **Nom de naissance**      | Birth surname    | Le nom qu’une personne portait à la naissance (nom de jeune fille), affiché sous la forme « née … ».                                              |
| **Panneau de détails**    | Details panel    | Le panneau de droite avec les données, la famille et la chronologie de la personne sélectionnée.                                                  |
| **Parent par alliance**   | Step-parent      | Un parent par le mariage et non par la naissance (beau-père, belle-mère) ; les parents adoptifs et d’accueil sont notés de la même façon.         |
| **Personne de référence** | Root person      | La personne à partir de laquelle partent les vues Ascendance et Descendance, marquée 🏠.                                                          |
| **Précision de la date**  | Qualifier        | Indique si une date est exacte, _vers_, _avant_ ou _après_ (`~`, `<`, `>`).                                                                       |
| **Sablier**               | Hourglass        | Une vue avec l’ascendance d’une personne au-dessus et sa descendance en dessous – en forme de sablier.                                            |
| **Union**                 | Partnership      | Une relation entre deux conjoints : mariage, union libre, fiançailles ou vie commune.                                                             |
