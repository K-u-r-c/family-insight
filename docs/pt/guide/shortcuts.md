# Atalhos de teclado

No programa, pressione <kbd>?</kbd> ou <kbd>F1</kbd> (ou escolha **Ajuda → Atalhos de teclado**)
para ver esta lista:

<Screenshot name="shortcuts" alt="A janela Atalhos de teclado com os grupos Arquivos, Edição, Árvore genealógica e Geral" />

<ShortcutTable />

As teclas do grupo **Árvore genealógica** funcionam quando a árvore tem o foco do teclado – clique
antes na árvore ou veja [Navegar com o teclado](./navigation#keyboard).

## Mais na barra de menus

| Ação              | Windows / Linux                                             | macOS                                               |
| ----------------- | ----------------------------------------------------------- | --------------------------------------------------- |
| Ampliar / reduzir | <kbd>Ctrl</kbd>+<kbd>=</kbd> / <kbd>Ctrl</kbd>+<kbd>-</kbd> | <kbd>⌘</kbd><kbd>=</kbd> / <kbd>⌘</kbd><kbd>-</kbd> |
| Voltar a 100 %    | <kbd>Ctrl</kbd>+<kbd>0</kbd>                                | <kbd>⌘</kbd><kbd>0</kbd>                            |
| Tela cheia        | <kbd>F11</kbd>                                              | <kbd>⌃</kbd><kbd>⌘</kbd><kbd>F</kbd>                |

A barra de menus também mostra o atalho ao lado de cada comando.
