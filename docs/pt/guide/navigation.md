# Navegar pela árvore

## Com o mouse ou o trackpad

- **Mova** a árvore arrastando uma parte vazia dela.
- **Amplie ou reduza** com a roda do mouse (ou com dois dedos no trackpad); o ponto embaixo do
  ponteiro fica no lugar. O gesto de pinça no trackpad amplia mais rápido.
- **Clique** em um cartão para selecionar a pessoa, dê um **clique duplo** para editá-la e clique
  com o **botão direito** para ver mais ações. Clique em uma parte vazia da árvore para desfazer a
  seleção.

Quando você seleciona alguém que está fora da área visível – por exemplo, na lista de pessoas –,
a árvore se desloca para mostrar essa pessoa.

## Controles de zoom e mapa geral

Os botões no canto inferior direito:

<Screenshot name="canvas-controls" alt="Os controles de zoom: 1 reduzir, 2 zoom atual (clique para 100 %), 3 ampliar, 4 ajustar à tela, 5 centralizar na pessoa selecionada, 6 mostrar ou ocultar o mapa geral" />

1. **Reduzir**
2. **Zoom atual** – clique nele para voltar a 100 %.
3. **Ampliar**
4. **Ajustar à tela** – mostra a árvore inteira.
5. **Centralizar na pessoa selecionada**
6. **Mapa geral** – mostra ou oculta o pequeno mapa no canto inferior esquerdo. O mapa mostra a
   árvore inteira com uma moldura em volta da parte que você está vendo; clique ou arraste nele
   para pular para outro lugar.

## Recolher ramos {#collapse}

Árvores grandes ficam mais fáceis de ler quando você oculta os ramos em que não está trabalhando.
Aponte para um cartão que tenha filhos e clique no pequeno botão **−** embaixo dele para ocultar
todos os descendentes dessa pessoa; **+** volta a mostrá-los.

<Screenshot name="collapse-branch" alt="O cartão de Tadeusz Wiśniewski com o pequeno botão embaixo dele (1) que oculta os seus descendentes" />

Os ramos recolhidos são salvos no arquivo junto com o [modo de visualização](./view-modes).

## Com o teclado {#keyboard}

Clique na árvore (ou pressione <kbd>Tab</kbd> até aparecer o link
**Ir para a árvore genealógica** e pressione <kbd>Enter</kbd>) e depois:

| Tecla                       | Ação                            |
| --------------------------- | ------------------------------- |
| <kbd>↑</kbd>                | ir para o pai ou a mãe          |
| <kbd>↓</kbd>                | ir para um filho ou filha       |
| <kbd>←</kbd> / <kbd>→</kbd> | ir para parceiro(a) ou irmão(ã) |
| <kbd>Enter</kbd>            | editar a pessoa selecionada     |
| <kbd>F</kbd>                | ajustar a árvore inteira à tela |
| <kbd>+</kbd> / <kbd>−</kbd> | ampliar / reduzir               |
| <kbd>0</kbd>                | voltar a 100 %                  |
| <kbd>Esc</kbd>              | desfazer a seleção              |

O primeiro toque em uma seta seleciona a [pessoa principal](./view-modes#root-person) (ou a
primeira pessoa). Todos os atalhos estão listados em [Atalhos de teclado](./shortcuts).

::: info Leitores de tela
A árvore funciona com leitores de tela: cada cartão tem um rótulo com o nome e as datas, e,
quando você se desloca com as setas, o programa anuncia a pessoa e os parentes mais próximos dela.

:::
