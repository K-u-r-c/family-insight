# Glossário

| Termo                       | Em inglês        | Significado                                                                                                              |
| --------------------------- | ---------------- | ------------------------------------------------------------------------------------------------------------------------ |
| **Ampulheta**               | Hourglass        | Uma visualização com os ascendentes de uma pessoa acima e os descendentes abaixo – no formato de uma ampulheta.          |
| **Arquivo `.finsight`**     | `.finsight` file | O arquivo em que o Family Insight salva uma árvore inteira, incluindo as fotos.                                          |
| **Ascendentes**             | Ancestors        | Os pais, avós, bisavós e assim por diante de uma pessoa; também o [modo de visualização](./view-modes) que os mostra.    |
| **Cartão**                  | Card             | O retângulo que representa uma pessoa na árvore.                                                                         |
| **CSV**                     | CSV              | Um formato de planilha em texto simples usado para [importar](./csv-import) e [exportar](./csv-export) pessoas.          |
| **Descendentes**            | Descendants      | Os filhos, netos e assim por diante de uma pessoa; também o modo de visualização que os mostra.                          |
| **Geração**                 | Generation       | Um nível da árvore: os pais ficam uma geração acima dos filhos.                                                          |
| **Linha do tempo**          | Timeline         | A lista de eventos da vida (nascimento, casamentos, filhos, falecimento) no painel de detalhes.                          |
| **Mapa geral**              | Overview map     | O pequeno mapa da árvore inteira no canto inferior esquerdo (minimapa).                                                  |
| **Meio-irmão, meia-irmã**   | Half-sibling     | Um irmão ou uma irmã com quem se tem só um dos pais em comum.                                                            |
| **Padrasto, madrasta**      | Step-parent      | Um pai ou mãe por casamento, e não por nascimento; pais por adoção e de acolhimento são registrados de forma semelhante. |
| **Painel de detalhes**      | Details panel    | O painel à direita com os dados, a família e a linha do tempo da pessoa selecionada.                                     |
| **Pessoa principal**        | Root person      | A pessoa a partir da qual partem as visualizações de ascendentes e descendentes, marcada com 🏠.                         |
| **Precisão da data**        | Qualifier        | Se uma data é exata, _cerca de_, _antes de_ ou _depois de_ (`~`, `<`, `>`).                                              |
| **Sobrenome de nascimento** | Birth surname    | O sobrenome com que a pessoa nasceu (nome de solteira), mostrado como “nasc. …”.                                         |
| **União**                   | Partnership      | Uma relação entre dois parceiros: casamento, união, noivado ou vida em comum.                                            |
