# Atualizações

O Family Insight verifica uma vez por dia se há uma nova versão disponível. Só a versão do
aplicativo é enviada ao GitHub, onde as versões são publicadas – nenhum dado seu.

## Quando há uma nova versão

Aparece um aviso no canto inferior direito:

<Screenshot name="update-available" alt="O aviso O Family Insight 1.2.0 está disponível com os botões Baixar, Notas da versão, Mais tarde e Ignorar esta versão" />

- **Baixar** – baixa a atualização em segundo plano; uma barra de progresso mostra o andamento.
- **Notas da versão** – as novidades desta versão.
- **Mais tarde** – oculta o aviso até a próxima vez que você abrir o programa.
- **Ignorar esta versão** – sem mais lembretes sobre esta versão (a próxima será oferecida).

<Screenshot name="update-notes" alt="A janela Novidades da versão 1.2.0 com títulos e uma lista das mudanças" />

Quando o download terminar, escolha **Reiniciar agora** – o Family Insight pede que você salve
antes as alterações não salvas e depois reinicia na nova versão. **Ao sair** instala a atualização
na próxima vez que você fechar o programa.

::: info Versões portátil, deb e macOS
O programa portátil para Windows, o pacote deb para Linux e o app para macOS não conseguem se
substituir sozinhos. Para eles, **Página de download** abre a página da versão, onde você baixa a
nova versão como de costume (veja [Instalação](./install#updating)).

:::

## Verificar agora ou desativar as verificações

No menu de configurações (**⚙**, no canto superior direito):

- **Verificar atualizações automaticamente** – ativado por padrão; desative se preferir atualizar
  manualmente.
- **Verificar agora…** – verifica na hora e informa se você já tem a versão mais recente. Ao lado
  aparece a hora da última verificação.

**Verificar atualizações…** também está no menu **Ajuda** (no macOS, no menu **Family Insight**).
