# Contributing

Thanks for helping with Family Insight! Everything you need is in the
**[developer documentation](https://k-u-r-c.github.io/family-insight/developer/)**:

- [Development setup](https://k-u-r-c.github.io/family-insight/developer/setup) – clone, install, run
- [Workflow and conventions](https://k-u-r-c.github.io/family-insight/developer/workflow) – issues,
  commits, project rules and the definition of done
- [Testing](https://k-u-r-c.github.io/family-insight/developer/testing) – unit and end-to-end tests
- [How-to guides](https://k-u-r-c.github.io/family-insight/developer/howto/ui-text) – translations,
  IPC, settings, file formats, languages …

In short:

1. Fork and clone, then `npm install` and `npm run dev`.
2. Create a branch, make your change and add tests.
3. Make sure `npm run check` and `npm run build` pass.
4. Open a pull request that references the issue (`Closes #123`).

Translations are especially welcome – see
[Add a language](https://k-u-r-c.github.io/family-insight/developer/howto/language).
